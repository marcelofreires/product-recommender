# Recomendador de Produtos RD Station

## Como Executar

1. Clone o repositório: `git clone <URL_DO_REPOSITORIO>`
2. Instale as dependências: `yarn install`
3. Inicie a aplicação: `yarn start:dev`
4. Abra a aplicação no seu navegador em [http://localhost:3000](http://localhost:3000)

> [!NOTE]
> O `json-server` roda o arquivo `db.json` em `localhost:3001`.
>
> Você pode ver os produtos em [http://localhost:3001/products](http://localhost:3001/products)

### Scripts Disponíveis

- `start`: Inicia apenas a parte frontend da aplicação em modo de desenvolvimento.
- `start:server`: Inicia apenas a parte backend da aplicação em modo de desenvolvimento.
- `start:dev`: Inicia simultaneamente a parte frontend e backend da aplicação em modo de desenvolvimento.
